# The-Nothing-Mod

A psychological horror mod developed by RealArqade.

## About this repository

This is the technical part of the mod only (loader and platform code, build files, tools, and the custom launcher), kept public so the community can help find and fix bugs. All story content has been removed: names are placeholders, text is blank, and every texture is a plain white picture showing its file name. The real mod is released separately.

This copy builds on its own, but it is not the real mod and is not meant to be played.
