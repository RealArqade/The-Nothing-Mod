# Hey. Please stop here. 🛑

If you've unzipped this jar, decompiled it, or opened it in a code editor, this note is for you.

This mod is part of an **ARG** (alternate reality game). It's built to be discovered **in the game and out in the world**,
by playing it, noticing things, and working them out together with other people.

Reading the code to find the answers isn't fair play. It skips the part the puzzle is actually for, and it spoils the
experience for you and for everyone who is solving it the intended way.

So, kindly:

- **Don't** go digging through the code, assets or data files for secrets.
- **Don't** share anything you find in there. Please keep it to yourself rather than spoiling it for everyone else.
- **Do** keep playing, keep looking around, keep asking questions with the community.

Everything you need to solve it is out in the open, in the game and the world around it. If you're stuck, being stuck is
part of it. Go back and look again. 🔍

Thank you for playing fair. It means a lot to the people who made this. 💜
